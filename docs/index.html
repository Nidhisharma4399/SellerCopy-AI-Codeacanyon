SellerCopy AI - Documentation

1. Requirements

  • Node.js 18 or newer (VPS, or Node hosting such as Render, Railway, DigitalOcean, cPanel with Node.js App)
  • An API key from OpenRouter (free tier available), OpenAI or Anthropic
  • Optional: a Stripe account to sell credit packs

2. Installation

npm install
cp .env.example .env      # Windows: copy .env.example .env
# edit .env: set JWT_SECRET (long random text) and AI_API_KEY
npm start

Open http://localhost:3000. The first account you register becomes the admin.

3. Configuration (.env)

  • AI_PROVIDER - openrouter (default), openai or anthropic
  • AI_MODEL - for OpenRouter's free tier use openrouter/free
  • These AI values can also be changed later in the browser: Admin → Settings (overrides .env)
  • FREE_CREDITS - credits given to new users
  • BASE_URL - your public site URL (required for Stripe redirects)
  • STRIPE_SECRET_KEY, STRIPE_WEBHOOK_SECRET - enable paid credit packs

3b. Features

  • 6 content types with tone and language options
  • Bulk CSV generation (product, features columns; max 25 rows per batch) with CSV download
  • History with search, copy and delete; dark mode
  • Admin: users, credits, site name, AI settings

Note: free AI models can be slow or rate limited. For a busy production site use a paid model.

4. Stripe setup

  1. In Stripe Dashboard copy your Secret key into .env.
  2. Developers → Webhooks → add endpoint https://YOUR-DOMAIN/api/stripe/webhook, event checkout.session.completed.
  3. Copy the signing secret into STRIPE_WEBHOOK_SECRET and restart.

5. Customising

  • Prompts/templates: TEMPLATES in server.js
  • Prices and credit packs: PACKS in server.js
  • Frontend source: client/. Edit, then run cd client && npm install && npm run build (outputs to public/)

6. Running in production

npm install -g pm2
pm2 start server.js --name sellercopy

Put Nginx or Caddy in front for HTTPS. Back up data.db regularly.

7. Security notes

Rate limiting, bcrypt password hashing and JWT auth are included. Always use a strong JWT_SECRET and HTTPS.

8. Third-party libraries

Express, better-sqlite3, bcryptjs, jsonwebtoken, dotenv, express-rate-limit, Stripe SDK, React, Vite - all MIT licensed.
